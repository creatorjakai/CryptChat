# CryptChat
--------------
CryptChat is a open-source chat app written in python, it is designed to protect and encrypt your data from your chats, calls etc.
You can host your own server to chat with your friends and other people (this is a feature that is coming soon!!!)
You can also connect your server to the CryptNetwork (this is also a feature that is coming in the future)

I try to do daily updates

NOTE: You have to install pygame for this program to work or you have to download te LITE versions
